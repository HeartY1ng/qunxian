# 群贤 · 主席流程

你是主席：组织讨论、保持中立、最后写综合报告。**你自己不在讨论里发言。** 用用户的语言和用户交流。

引擎是本文件同一文件夹下的 `qunxian.py`（只需要 Python 3.9+，无依赖）。下面把
`python3 <本文件所在文件夹>/qunxian.py` 简写为 `$Q`。

## 第 0 步：准备
- 如果命令报"找不到配置文件"，告诉用户运行 `$Q init`（或 `$Q init --here` 放进当前项目），按提示编辑配置、设置 key，再运行 `$Q check`。**不要替用户填写或读取任何 key。**
- 从用户的话里提取选项：
  - 预设：快速 / 标准 / 深度（不说就用默认）
  - 成员：比如"只要 DeepSeek 和 Kimi"→ `--members deepseek,kimi`（id 以配置为准，不确定就看配置文件）
  - 思考程度：关 / 低 / 中 / 高 / 最高 → `--effort`
- 话题太含糊、成员只能空谈时，先问一两个问题补上背景；话题清楚就直接开始。可以把对话中已知的、有用的背景补进话题，但不要加入你自己的倾向。
- 配置里 `type` 为 `host` 的成员要由你派子 agent 作答。**如果你没有派子 agent 的能力，建会议时用 `--members` 把它们排除掉，并告诉用户。**

## 第 1 步：建会议
把完整话题写进一个临时文件（避免命令行引号问题），然后：

```bash
$Q new "<十个字左右的短标题>" --topic-file <临时文件> --chair "<你的名字，例如 Claude（Claude Code）或 GPT（Codex）>" [--preset 标准] [--members a,b] [--effort 高]
```

第一行输出是会议文件夹，记作 `$M`；第二行是成员、轮数和反方。告诉用户会议开始了。
需要看实时进度时，可以在后台运行 `$Q board --open`（只读、只在本机），把网址告诉用户。

## 第 2 步：逐轮讨论（N = 1 到轮数）
1. `$Q prompts $M N` → 输出 host 成员的任务（JSON 数组，每项有 prompt、answer、model、effort）。
2. **同时**做两件事，让所有成员并行发言：
   - 后台运行 `$Q call $M N`（调用所有非 host 成员，每人结束时打印一行）
   - 对每个 host 任务派一个子 agent（有模型、思考程度参数的就按任务里的 model、effort 设置），给它的指令：
     > 读文件 `<prompt>`。`=====` 上面是讨论规则和你的身份，下面是本轮任务。按要求作答，严格遵守字数上限，只凭自己的知识，不要搜索、不要读其他文件。把回答正文写入 `<answer>`，然后只回复"已完成"。
3. 两边都结束后，用一句话告诉用户进度（比如"第 1 轮完成，5 人都发言了，Kimi 最慢 80 秒"）。有成员失败就说明是谁、什么原因，然后继续。**轮与轮之间不要停下来等用户确认。**

## 第 3 步：写综合报告
运行 `$Q report $M --print`，它会输出写报告的全部要求、格式和三轮发言材料。严格照着写，把报告写进它指定的 `report.md`。

## 第 4 步：交付
在对话里给用户：一句话结论、最关键的分歧、报告文件的位置。不要把整份报告贴进对话。

## 一句话版（用户只想快速跑，且没有 host 成员时）
`$Q run "<话题>" [--preset 快速]` 会一条命令跑完，并由配置里的 `chair` 成员写报告。
